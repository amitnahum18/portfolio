# Project image loops

19 silent two-second MP4 previews were rendered in the Higgsfield cloud sandbox on 2026-10-10. They use a restrained 1.8% cyclic camera zoom, returning to the initial framing. This is cloud image animation through FFmpeg, not generative object motion. The account rejected Seedance and Grok AI video generation because paid plan access was required.

Each clip is 640 x 426, 24 fps, 48 frames, H.264 with fast-start metadata. All 19 together occupy 919,690 bytes. Documentary plots and screenshots preserve their proportions with padding; conceptual covers retain their composition. The source images remain available in the project pages.

The website requests a clip only when its card is hovered or focused with a keyboard. Previews stop on exit, lost focus, route/filter changes, hidden tab, browser blur or Escape. Reduced-motion preferences disable playback. Touch pointer hover does not start a preview. Mobile retains the static image presentation.

Validation: cloud ffprobe verified all 19 durations, frame counts, dimensions and absence of audio. BridgePulse beginning/middle/end frames and representative JEV, plot and diagram frames were visually inspected. Page checks validate asset paths, lazy loading, decorative media semantics and all 21 routes. Interaction checks cover reduced motion, lazy source assignment, start/stop and route cleanup.
